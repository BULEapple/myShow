一个用于快速初始化前端项目的命令行脚手架工具，通过交互式问答生成项目模板。

## 特性

- 交互式问答选择技术栈与配置
- 内置多套项目模板
- 支持自定义模板仓库

## 使用方式

```bash
npm install -g my-cli
my-cli create my-app
```

## 技术栈

Node.js、TypeScript、commander、inquirer。
