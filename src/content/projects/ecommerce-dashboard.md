一个面向中小电商的后台管理系统，提供商品管理、订单处理、库存预警与数据看板等功能。

## 核心功能

- 商品管理：SKU、分类、上下架
- 订单处理：状态流转、批量操作
- 数据看板：销售额、订单量趋势图表
- 权限控制：基于角色的访问控制

## 技术栈

前端 React + TypeScript + Tailwind CSS，后端 Node.js，数据库 PostgreSQL，缓存 Redis。

## 成果

- 支撑日均 1w+ 订单处理
- 首屏加载耗时降低约 40%
